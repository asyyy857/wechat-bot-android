# data/ 目录里都是什么

升级（重装新版本）时 **data/ 整个目录不会被覆盖** —— 你的配置、聊天流水、
记忆库、表情包都留在这里。程序本体在 `../app/`，覆盖升级只动那一半。

| 文件 / 目录 | 是什么 | 能不能删 |
|---|---|---|
| `config.yaml` | 主配置（群名、昵称、API Key、频率、开关） | 别删；改错了从 `app/defaults/config.yaml` 拿回模板 |
| `rules.yaml` | 关键词规则表（命中就直回，0 Token） | 别删 |
| `personas/` | 人设（模型的 system prompt）。可放多套，按 `behavior.persona_schedule` 分时段出场 | 别删 |
| `表情包/` | 发表情包用的图库，文件名 = 标签 | 可以加图 |
| `美图库/` | 「看看腿」这类本地图集（按规则名取） | 可以加图 |
| `font_profiles/` | 字体档案（微信不是默认字体时用），见《字体与OCR.md》 | 可以删（删了就回到默认字号） |
| `记忆库.json` | 记「人」和「梗」，按相关性注入 prompt | 可以删（清零） |
| `名字库.json` | 读屏用：把「昵称：正文」粘一起的消息切开。机器人启动时自动重建 | 可以删 |
| `群情摘要.json` | 每小时的群情摘要（超出 10 分钟窗的群背景） | 可以删 |
| `chat_log.json` | 机器人读到的群聊流水（本地，不联网） | 可以删（历史清零） |
| `sent.jsonl` | 真发出去的话（含人工改过的稿） | 可以删 |
| `rejects.jsonl` | 你否掉的说法（模型会避开） | 可以删 |
| `*.log` | 日志在 `../logs/`，不在这个目录 | — |

## 隐私提醒

`data/` 在手机的共享存储（`/sdcard`）上 —— **同一个手机上有存储权限的 App 都读得到**。
如果这让你不舒服：
  · DeepSeek 的 API Key **别写进 config.yaml**，用容器里的密钥文件
    （`/root/.dsh/.deepseek_key`，权限 600）或环境变量 `DEEPSEEK_API_KEY`；
  · 或者把整个数据目录挪到容器私有目录：设环境变量
    `WXBOT_DATA_DIR=/root/wechat-data`（见《配置手册.md》），再把 data/ 里的东西搬过去。
